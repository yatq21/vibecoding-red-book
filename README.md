# Red Book (小红书) 移动端原型（静态 HTML）

## 运行
- 方式 1：直接用浏览器打开 `index.html`
- 方式 2：用 VS Code Live Server 打开 `index.html`

## 页面
- `index.html`：入口（带底部 Tab 的壳）
- `pages/home.html`：首页信息流
- `pages/search.html`：搜索/发现
- `pages/detail.html`：笔记详情/评论
- `pages/publish.html`：发布
- `pages/messages.html`：消息
- `pages/profile.html`：我的

## 说明
- 纯静态原型，使用 iframe + hash 路由模拟“页面切换”。
- 你可以继续替换占位图片、文案、交互逻辑。
